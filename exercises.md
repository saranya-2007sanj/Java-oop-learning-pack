**Task:** Write an Account class with a private balance. deposit() and withdraw() must reject non-positive amounts (IllegalArgumentException) and overdrafts (IllegalStateException).

<details><summary>Solution</summary>

```java
static class Account {
    private double balance;
    void deposit(double amt) { if (amt <= 0) throw new IllegalArgumentException("amount must be positive"); balance += amt; }
    void withdraw(double amt) {
        if (amt <= 0) throw new IllegalArgumentException("amount must be positive");
        if (amt > balance) throw new IllegalStateException("insufficient funds");
        balance -= amt;

    double getBalance() { return balance; }
}
```

## Exercise 20 - Generics

**Task:** Write Box<T extends Comparable<T>> with isBigger(Box<T>) and a generic static max(List<T>) that works for Integer and String.

<details><summary>Solution</summary>

```java
static class Box<T extends Comparable<T>> {
    final T value;
    Box(T value) { this.value = value; }
    boolean isBigger(Box<T> o) { return value.compareTo(o.value) > 0; }
}
static <T extends Comparable<T>> T max(List<T> xs) {
    T best = xs.get(0);
    for (T x : xs) if (x.compareTo(best) > 0) best = x;
    return best;
}
static void ex20() {

    check(max(List.of(3, 9, 4)) == 9 && max(List.of("pear", "apple", "zebra")).equals("zebra"), "max");
}
```
