# Responsible AI Use - Ethics Statement

1. **Verify all code.** No AI-generated code is included unless it was compiled and run (`./run_all.sh`; log in `verification/run_log.txt`). Every example has self-checks that throw `AssertionError` on failure.
2. **Explain every line.** Nothing is submitted that the author cannot explain; each concept note links to a runnable example and a quiz question.
3. **Credit analogies and sources.** Definitions follow the Oracle Java Tutorials and official Java documentation; analogies are common teaching comparisons reworded for this pack and are labelled as such. Any analogy taken from a specific book, lecture or website must be cited by the author in the research report.
4. **No fabricated evidence.** The AI-tool log, hallucination tests and before/after tables are only filled with results the author actually observed. Blank cells mean "not yet run".
5. **Safety.** Examples contain no file, network or system access; no AI advice about security or deployment is used without checking official docs.
6. **Outdated information.** Java features are tagged by version (e.g. pattern-matching `instanceof` needs Java 16+, default methods Java 8+). Check against the JDK version you actually run.
7. **Privacy and integrity.** No personal data is sent to AI tools. AI use is disclosed per the prompt library, and the final submission follows the institution's academic-integrity policy.
